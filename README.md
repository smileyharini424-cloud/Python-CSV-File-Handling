# Python CSV File Handling

## Explanation

This program demonstrates how Python can work with CSV (Comma-Separated Values) files using the built-in `csv` module. It creates a CSV file, stores student information, reads the data, and displays it.

## Problem Statement

Write a Python program to create a CSV file containing student details and read the stored information using Python's `csv` module.

## Features

* Creates a CSV file
* Writes column headings
* Stores student records
* Reads CSV data
* Displays student information

## How It Works

1. The `csv` module is imported.
2. A CSV file is opened in write mode.
3. Column headings and student records are written.
4. The file is opened in read mode.
5. Each row is read and displayed.

## Technologies Used

* Python 3
* `csv` module
* CSV files

## Program Flow

Start → Import CSV Module → Create CSV File → Write Data → Read CSV File → Display Records → End

## Sample Input


## Sample Output

```text
Student Details:

Name: Anu, Age: 21, Course: ECE
Name: Ravi, Age: 20, Course: EEE
```

## Key Learning

* CSV files store tabular data.
* Python provides the built-in `csv` module for CSV operations.
* `csv.writer()` is used to write data.
* `csv.reader()` is used to read data.
* CSV files are useful for storing structured data.
